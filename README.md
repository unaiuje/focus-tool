# Academia Pro

Soy un estudiante de 4rto de la eso que necesita un sistema para poder organizarme bien el curso, para luego poder sacar la maxima nota posible.Investiga cuales son las mejores practicas de estudio, organizacion, gestion... proponme varias maneras que se adapten a mi, a mi caracter, soy una persona que me cuesta ponerme a estudiar pero con poco saco buena nota. El objetivo es utilizar esta herramienta en mi dia a dia para cumplir el objetivo sacar la mejor nota y prepararme para bachillerato.
